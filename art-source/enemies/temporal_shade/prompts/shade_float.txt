# Project: CHRONO – THE FRACTURED DIVINITY
# Design Document: docs/art/SHADE_DESIGN.md

================================================================================
GRID & TARGET FORMAT:
================================================================================
- Dimensions: 128x32 pixels total sprite sheet (4 frames horizontal, 1 row)
- Frame Size: 32x32 pixels per frame
- Frames: 4-frame vertical hovering bob cycle
  - Frame 0: Neutral hover (hovering 4px above ground)
  - Frame 1: Apex rise (+2px vertical displacement, chest core glows slightly brighter)
  - Frame 2: Top hover peak, mist wisps trail downward
  - Frame 3: Gentle settling descent back toward neutral
- Background: 100% transparent (8-bit alpha channel)
- Collision Hitbox: 22x22 pixels centered at (5, 5)
- Animation Speed: 6 FPS loop
