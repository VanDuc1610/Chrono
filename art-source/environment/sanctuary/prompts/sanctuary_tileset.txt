# Project: CHRONO – THE FRACTURED DIVINITY
# Design Document: docs/art/ENVIRONMENT_GUIDE.md

================================================================================
GRID & TARGET FORMAT:
================================================================================
- Dimensions: 128x128 pixels total tileset sheet (4 columns x 4 rows)
- Tile Size: 32x32 pixels per tile
- Layout (16 Tiles):
  - Row 0: Plain floor flagstones, cracked floor, engraved chronal floor, cyan fissure floor
  - Row 1: Wall top cornice, wall center face, wall base edge, pillar base
  - Row 2: Broken pillar mid, broken pillar cap, left wall corner, right wall corner
  - Row 3: Altar top-left, altar top-right, altar bottom-left, altar bottom-right
- Background: Solid dark or seamless tile textures (transparent for props)
- Palette: Dark slate navy (#1b2234), weathered slate (#29344c), bronze trim (#8c6628), cyan rune glow (#00c8ff)

RECOMMENDED AUTOMATIC1111 WEBUI SETTINGS:
================================================================================
- Checkpoint / Model: SD 1.5 Pixel Art model (or SDXL Pixel Art model downscaled)
- Sampler: DPM++ 2M Karras or Euler a
- Steps: 28
- Total Canvas Width: 512 px (downscaled to 128 px) or native 128 px
- Total Canvas Height: 512 px (downscaled to 128 px) or native 128 px
- CFG Scale: 7.5
